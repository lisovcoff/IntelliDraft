# IntelliDraft

**Интеллектуальный модуль для анализа документов и подготовки проектов резолюций с помощью ИИ.**

IntelliDraft — проект надстройки, предназначенной для автоматизации подготовки резолюций по входящим официальным документам. Модуль должен анализировать содержание документа, определять его предметные области, предлагать подходящих исполнителей и формировать проект резолюции в официально-деловом стиле.

Цель проекта — сократить объём рутинной работы руководителя, сохранив за ним контроль над итоговым решением.

## Основные возможности

- **Обработка документов:** приём структурированных JSON-данных, обычного текста и файлов документов.
- **Классификация тематики:** определение одной или нескольких предметных областей, например финансов, информационной безопасности, кадровых и правовых вопросов.
- **Рекомендация исполнителей:** подбор основного исполнителя и соисполнителей на основе тематики документа, правил распределения и исторических данных.
- **Генерация резолюций:** подготовка проекта поручения в официально-деловом стиле с учётом контекста документа и примеров предыдущих резолюций.
- **Рекомендация срока:** предложение планового срока исполнения с учётом содержания документа.
- **Определение типа резолюции:** рекомендация варианта «На исполнение» или «К сведению».
- **Контекстная генерация:** использование исторических документов и резолюций с помощью подходов RAG и few-shot prompting.
- **Контроль со стороны человека:** возможность просматривать, редактировать, отклонять и генерировать заново предложенную резолюцию до её отправки.

> **Важно:** резолюция не должна отправляться без явного подтверждения руководителя.

## Как это работает

1. Система получает входящий документ и предварительно обрабатывает его.
2. ИИ анализирует содержание и определяет предметные области.
3. Модуль предлагает исполнителей, тип резолюции и срок исполнения.
4. Формируется черновик резолюции для проверки руководителем.
5. Руководитель при необходимости редактирует черновик и подтверждает отправку через существующую систему.
